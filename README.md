# Pokémon App – Angular Pokedex

Application Angular permettant de gérer une liste de Pokémon avec fonctionnalités CRUD complètes (ajout, modification, suppression), authentification avec un Guard, filtrage, affichage des détails et persistance via local storage.

Déployée sur Firebase  
Démo en ligne : https://pokedex-9ae72.web.app/login

---

## Fonctionnalités

-Recherche et filtrage des Pokémon  
- Liste complète affichée sous forme de cartes  
- Ajout d’un Pokémon  
- Modification d’un Pokémon  
- Suppression d'un Pokemon
- Persistance des données via **Local Storage**  
- **Routing Angular** pour navigation entre pages  
- Mise en place d'une authentification géré par le **guard**
- Interface responsive et propre

---

# Stack technique

- **Angular** (TypeScript)
- **HTML / CSS**
- **Local Storage**
- **Firebase Hosting**
- **Angular Router**

# Installation & exécution du projet

###  Cloner le projet

git clone https://github.com/oumar120/pokemon-app.git
cd pokemon-app
# Installer les dépendances
npm install
# Lancer le serveur de développement
ng serve

Le projet sera accessible sur:

http://localhost:4200/


Compiler en production :

ng build --prod

Déploiement Firebase

Commande utilisée pour déployer :

ng build
firebase deploy
